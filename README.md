# Shelf

Paste a YouTube link and Shelf remembers where you stopped in every video.

Open it: https://mokingsacc.github.io/shelf/

- `index.html` and `icon.png` are the app (one file, built).
- `dev/` holds the source and tests. Run `node dev/build.mjs` to rebuild `index.html`, `node dev/test/core.test.cjs` and `node dev/test/e2e.mjs` (needs Playwright) to test.
